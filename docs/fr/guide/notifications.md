# Notifications

Toppo vous prévient de ce qui se passe sur les tickets que vous suivez, dans l’application et par e-mail.

## Qui est prévenu de quoi

Vous suivez un ticket quand vous l’avez signalé, quand il vous est assigné, quand vous le commentez, ou quand vous cliquez sur **Suivre**. **Ne plus suivre** l’arrête pour de bon, même si vous commentez de nouveau.

| Ce qui se passe                | Qui est prévenu                                                                |
| ------------------------------ | ------------------------------------------------------------------------------ |
| Un nouveau ticket              | Les membres des rôles prévenus de chaque nouveau ticket (**Nouveaux tickets**) |
| Un ticket assigné              | La nouvelle personne assignée, et ceux qui suivent le ticket                   |
| Un commentaire                 | Ceux qui suivent le ticket, et les personnes qu’il mentionne                   |
| Un commentaire modifié         | Seulement les personnes qu’il mentionne pour la première fois                  |
| Un statut changé               | Ceux qui suivent le ticket                                                     |
| Un ticket marqué comme doublon | Ceux qui suivent le ticket                                                     |

Vous n’êtes jamais prévenu de ce que vous avez fait vous-même, ni d’un ticket que vous ne pouvez pas voir.

## La cloche

La cloche dans la barre du haut compte ce que vous n’avez pas lu, et liste les 20 dernières : ouvrez-en une pour aller à son ticket, ce qui la marque comme lue. **Tout marquer comme lu** remet le compte à zéro ; **Tout voir** ouvre la page **Notifications**, 20 par page. Les notifications lues partent au bout de 90 jours.

## Par e-mail

Une notification que vous n’avez pas lue dans les 5 minutes vous est envoyée par e-mail, dans votre langue, quand l’[e-mail](../self-hosting/email) est configuré. Dans **Mon compte › Notifications**, choisissez quels types vous arrivent par e-mail :

- Nouveaux tickets (si votre rôle vous en prévient)
- Tickets qui me sont assignés
- Assignations des tickets que je suis
- Commentaires sur les tickets que je suis
- Mentions
- Changements de statut des tickets que je suis
- Doublons parmi les tickets que je suis

Tous sont activés au départ. Dans l’application, vous êtes prévenu de tous.
