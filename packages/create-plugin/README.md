# @toppo-tracker/create-plugin

Starts a [Toppo](https://toppo-tracker.app) plugin:

```sh
npm create @toppo-tracker/plugin issue-digest
cd issue-digest
npm install
npm test
npm run build
```

The folder's name is the plugin's id. It gets one action and its test, ready to build with `toppo plugin build` and test with `@toppo-tracker/plugin-testing`.

The guide: https://toppo-tracker.app/plugins/
