# @toppo-tracker/cli

The `toppo` command: Toppo's tools for the command line.

```sh
toppo plugin build [directory] [--out <directory>]
```

`toppo plugin build` bundles a plugin into the zip an administrator installs in **Settings › Plugins**: its server code, its screens apart, its version and its logo, each checked as Toppo will check it. It refuses what Toppo would refuse, with the reason.

The guide: https://toppo-tracker.app/plugins/
